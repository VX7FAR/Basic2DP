Basic2DP is a 2D translation physics engine that is capable of detecting collision, bouncing back, forces, etc.
It is very simple as this will act as the base for a further bigger project however I might add more to it if I ever feel like it.

For collision I had used GJK(Gilbert Johnson Keerthi) algorithm and since I am working on translation only I dont think someone will be bothered by it not having any rotation.
